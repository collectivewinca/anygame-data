# Minigame distribution terms methodology

Status: stub for v0.1 (August 2026). Expand when the initial table ships.

## Purpose

Comparable, source-linked terms across mini-game / instant-game distribution platforms for indie founders.

## v0.1 platforms

1. WeChat Mini Games  
2. TikTok Mini Games  
3. Discord Activities  

## Sources (planned)

- WeChat: GameTeahouse / industry reports (manual; English docs limited)
- TikTok: official developer docs (`developers.tiktok.com` mini-games overview)
- Discord: developer newsletter + public Activity docs; conference notes as secondary

## Cadence

- **Monthly:** diff-check public English docs pages; append `minigame-terms/changelog.md` after human review  
- **Quarterly:** full row refresh (target months: Aug / Nov / Feb / May)  
- Every cell: `last_verified` + `source_link`

## What this repo does not do

Live form submissions or panelist-reported term tips stay in PocketBase / private `anygame-panel` until verified and merged here.
